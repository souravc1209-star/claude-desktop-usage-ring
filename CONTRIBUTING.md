# Contributing

Open [the demo](https://souravc1209-star.github.io/claude-desktop-usage-ring/demo/) or run the [local copy](docs/installation.md). The [validation guide](docs/review.md#reproduce-the-checks) covers Node.js, Playwright setup, and focused checks.

Bug reports are most useful with a browser version, viewport, scenario, and steps to reproduce. Include screenshots or traces from the synthetic demo only. Use [GitHub Issues](https://github.com/souravc1209-star/claude-desktop-usage-ring/issues) for ordinary bugs and [private reporting](SECURITY.md) for vulnerabilities.

Small fixes to accessibility, UI resilience, tests, and documentation are welcome. For a wider change, describe the use case in an issue first. Keep browser runtime code dependency-free and test new behavior through the demo or the widget’s public entry point. The project scope excludes authenticated Claude requests, private accounts, launcher code, and credentials.
