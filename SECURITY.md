# Security reporting

Report suspected vulnerabilities in the current release through [GitHub private vulnerability reporting](https://github.com/souravc1209-star/claude-desktop-usage-ring/security/advisories/new). Include the affected version, impact, and synthetic steps to reproduce. Remove account data, tokens, and personal information before sending logs or screenshots.

For non-security bugs, use [GitHub Issues](https://github.com/souravc1209-star/claude-desktop-usage-ring/issues). See the [privacy review](docs/review.md#privacy-and-application-security) for the public demo’s security boundaries.
